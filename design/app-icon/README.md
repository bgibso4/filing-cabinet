# App icon

Scan corners around a folder, in the app's own colours.

| | Background | Corners | Folder |
| --- | --- | --- | --- |
| Light | #f2f2f7 | #1c1c1e | #c0533a |
| Dark | #1c1c1e | #f2f2f7 | #c0533a |

Tinted and clear are generated by iOS from these layers.

## Files

- `layers/`: 1024 × 1024 SVGs, one per layer, all shapes as solid fills (no strokes). `1-background-*` and `2-corners-*` come in light and dark; `3-folder.svg` is shared.
- `preview/`: the flattened icon in light and dark, as SVG and 1024 × 1024 PNG.

Square, no rounded corners, no transparency in the background: iOS applies the mask.

## Setting it up

Build a `.icon` file in Apple's Icon Composer: background colour per appearance, then the corners layer (light and dark versions) and the folder layer. Add the `.icon` file to the Xcode project as the app icon. Keep the layers flat; Icon Composer adds the Liquid Glass light and depth.
