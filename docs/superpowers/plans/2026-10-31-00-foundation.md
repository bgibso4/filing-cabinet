# Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the whole engineering loop (project, package, lint, hooks, all five test layers, CI, agent docs, GitHub remote) and prove it end to end with one tiny real feature: the first-launch Home screen.

**Architecture:** A thin XcodeGen app target over a local Swift package, `FilingCabinetKit`. Mac-buildable modules (`Core`, `ScreenModels`) carry the logic and run in the Fast loop on macOS; the iOS-only `Screens` module carries SwiftUI views, the design system and generated tokens. Every rule in the foundations doc is enforced by a tool introduced here.

**Tech Stack:** Xcode 27 / iOS 27 SDK, Swift 6 language mode, SwiftUI, Observation, Swift Testing, XCTest (UI tests only), swift-snapshot-testing, XcodeGen, SwiftLint, `swift format`, Periphery, bats, GitHub Actions (`xcode-27` runner).

**Spec:** `docs/superpowers/specs/2026-10-31-engineering-foundations-design.md` (read it first; this plan implements its §10 item 1). Product source of truth: `docs/superpowers/specs/2026-10-10-filing-cabinet-requirements.html`. Screen: `design/screens/01-06-empty-home.png` (light) and `01-09-empty-home-dark.png`; source `design/components/Home.dc.html` with props `{state: "first", favorites: 0}`.

## Global Constraints

- iOS 27.0 minimum, iPhone only (`TARGETED_DEVICE_FAMILY: "1"`), portrait only, English only. No `#available` branches.
- Swift 6 language mode, Approachable Concurrency on. Default isolation `MainActor` for `ScreenModels`, `Screens` and the app; `nonisolated` for `Core`. Banned: `Task.detached`, `@unchecked Sendable`, disabling concurrency checking.
- Package: `Packages/FilingCabinetKit`, `// swift-tools-version: 6.2`, `platforms: [.iOS(.v27), .macOS(.v27)]`, `defaultLocalization: "en"`, `package` access between modules (not `public`, except what the app target needs).
- Mac-buildable modules never import SwiftUI, UIKit or VisionKit.
- Bundle id `com.cadre.filingcabinet`; display name "Filing Cabinet". Team ID committed in `Signing.xcconfig` (confirm the value with Ben in Task 1; Beacon uses `TD7DDZ2T78`).
- The `.xcodeproj` is generated and gitignored. Never hand-edit it.
- Every user-facing string is in the owning module's `Localizable.xcstrings` and looked up with `bundle: #bundle`. Copy uses middots (" · "), never em dashes. The Scan button always says "Scan".
- Colours, spacing, radii and type only from the token generator's output. Titles in New York (`.serif`), everything else SF Pro. Radii 14 / 6 / pill. No shadows.
- `os.Logger` (subsystem `com.cadre.filingcabinet`, category = module), never `print()`. `try?` only with a comment saying why.
- One primary type per file. Collaborators injected; no singletons. Protocols only at real seams (here: `Analytics`).
- Third-party packages: swift-snapshot-testing only (TelemetryDeck is connected later, before TestFlight). Every package pinned with `exact:`.
- Agents dispatch `ios-verifier` before claiming anything builds or passes.
- No personal documents anywhere in the repo.

## Review Focus

1. **A fresh clone with no local files** (no `Signing.local.xcconfig`, no generated project, no `.build`). `make setup && make ci` must succeed with nothing else. Test: Task 9 CI runs on a clean checkout; Task 1 Step 7 runs `make build` after `git clean -xfd`.
2. **The Fast tests fail to *compile*** (not just fail). The Stop gate must block, never treat a build error as "no failures". Test: Task 8 `stop gate blocks when make fast exits non-zero with no test output`.
3. **A required tool is missing** (`jq`, `swiftlint`, `xcodegen`) in a new worktree. Hooks and Make targets must fail loudly with the install command, not silently pass. Tests: Task 8 `hooks fail closed with a message when jq is missing`; Task 2 Step 6.
4. **Two agents finish at once in the same worktree.** The second Stop gate waits for the lock instead of corrupting `.build` or reporting a bogus failure. Test: Task 8 `concurrent stop gates serialize on the lock`.
5. **Largest accessibility text size on Home.** Every row's name and subtitle wrap instead of truncating, and the Scan button stays reachable. Test: Task 6 snapshot `home_first_ax5`, Task 7 `scanButtonHittableAtLargestText`.
