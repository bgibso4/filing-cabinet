# Which simulator test classes a changed path can affect (read by scripts/affected-tests.sh, `make affected`).
#
#   <path prefix> <Class> ...   a changed path under the prefix runs those classes
#   <path prefix> ALL           runs every simulator test (shared code)
#   <path prefix> NONE          runs nothing (can't affect the simulator tests)
#   SELF <Class> ...            classes that only their own files affect (so the map check accepts them)
#
# A path takes the union of every rule whose prefix matches; "*.md" matches Markdown anywhere. A path no rule
# matches runs everything, so a gap here costs time, never coverage. Test files need no rule: a file under UITests/ or
# SnapshotTests/ runs the *Tests types it declares or extends, and SnapshotTests/__Snapshots__/<Class>/ runs <Class>.
